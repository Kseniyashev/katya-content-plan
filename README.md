# Контент-план · Катя · 27.07–02.08.2026

Системная версия недельного контент-плана, собранная Проходом A.

**Источник:** `experts/katya/plans/2026-W31/plan.yaml` — там же версия алгоритма, срез
ДНК-лифта и остальной провенанс. ⚠️ Номер версии здесь больше не дублируется: он уже
один раз протух на четыре релиза (стояло v1.3, когда алгоритм был v1.7), потому что
второй копии числа никто не обновляет.

**Живая страница:** https://kseniyashev.github.io/katya-content-plan/

Что внутри: распределение слотов недели (работы, источники, производство), 35 рилсов основного
аккаунта, сторис и карусели, A/B-стенд хуков на прокладках, действия саппорта, Telegram, Threads.
Плюс блок ёмкости съёмочного дня — считается моделью производственных минут.

**Страница генерируется, руками не правится:**

```
python3 engine/plan_render.py experts/katya/plans/2026-W31/plan.yaml --projection system
cp experts/katya/plans/2026-W31/render/system.html <этот репозиторий>/index.html
```

Правки вносятся в `plan.yaml` и страница пересобирается — иначе они потеряются
при следующей сборке. Все распределения и доли считаются из слотов: рукописные
числа уже расходились с содержимым (в прошлой версии стояло «Hub-рубрики 3»
при фактических 2).

Статус слотов `draft`: темы и углы ждут аппрува эксперта. Поля «Сценарий», «Монтажный сценарий»
и «Ссылка на голосовое» пустые по построению — их заполняет Проход B.
